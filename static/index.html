The reply race

Hundreds of replies to a post, one question to answer about each of them. Pick the question and the models, start the race, and see which model is the fastest, the cheapest, and gets the most answers right.

How do the two kinds of model answer?

An LLM answers by writing

  1. Reads a prompt with the replies and the allowed answers
  2. Writes its answer word by word, and you pay for each one
  3. A program reads that text. If it is badly formed, the answer is lost.
{"i": 3, "opinion": "negative"}

A decision model answers by choosing

  1. Reads the post, one reply, and the question with its possible answers
  2. Scores every possible answer at once. It writes nothing.
  3. Returns a probability for each answer. The program picks the top one.

Cohen's kappa
Right answers with the lucky guesses removed. 1 is perfect, 0 is no better than guessing. It matters when one answer is very common: always answering "no" to the making-of question gets 96% right answers but a kappa of 0.

For yes/no questions: how many of the replies the answer key marks "yes" the model also found.
Sure
Decision models give a probability. When it falls between 0.3 and 0.7 the model is not sure, and code can send the reply to a person.
